# CET-4 大学英语四级课程包教学大纲

## 一、课程概述

本课程包面向准备大学英语四级考试（CET-4）的学习者，基于《全国大学英语四、六级考试大纲（2016年修订版）》设计。课程涵盖四级大纲要求的约4500个词汇及核心语法体系，按10个主题单元循序渐进展开。

### 目标学习者

- 已掌握高中英语3500词汇基础的大学生
- 计划参加CET-4考试的考生
- 需要系统性提升英语综合应用能力的学习者

### 教学目标

1. 掌握4500个四级大纲词汇及其用法
2. 熟练运用10大核心语法结构
3. 能听懂日常对话、短篇新闻和学术讲座
4. 能阅读一般性题材的英文文章
5. 能就熟悉话题写出120-180词的短文
6. 能将中文段落翻译为英文

## 三、语法体系

### 四级必考十大语法点

1. **动词时态与语态**（Units 1-3）

   - 一般现在时、一般过去时、一般将来时
   - 现在进行时、过去进行时、将来进行时
   - 现在完成时、过去完成时、将来完成时
   - 现在完成进行时、过去完成进行时
   - 各种时态的被动语态

2. **情态动词**（Unit 3）

   - can/could, may/might, must, shall/should, will/would
   - 情态动词表推测、建议、义务、能力

3. **定语从句**（Unit 4）

   - 限制性定语从句（who, whom, which, that, whose）
   - 非限制性定语从句
   - 关系副词（when, where, why）
   - 介词 + 关系代词

4. **名词性从句**（Unit 5）

   - 主语从句、宾语从句、表语从句、同位语从句
   - that/whether/if 引导词的用法区别

5. **状语从句**（Unit 6）

   - 时间状语从句、地点状语从句
   - 原因状语从句、结果状语从句
   - 条件状语从句、让步状语从句
   - 目的状语从句、方式状语从句、比较状语从句

6. **非谓语动词——不定式**（Unit 7）

   - 不定式作主语、宾语、表语、定语、状语、补语
   - 不定式的完成式、进行式、被动式
   - 不定式符号 to 的省略情况

7. **非谓语动词——动名词与分词**（Unit 8）

   - 动名词作主语、宾语、表语
   - 现在分词与过去分词的区别
   - 分词作定语、状语、补语
   - 独立主格结构

8. **虚拟语气**（Unit 9）

   - if 引导的非真实条件句（与现在/过去/将来事实相反）
   - 省略 if 的倒装虚拟
   - wish/if only 引导的虚拟
   - suggest/demand/insist 等词后的虚拟
   - It is + adj./done that 句型中的虚拟
   - 含蓄虚拟（without/but for）

9. **倒装与强调**（Unit 10）

   - 全部倒装与部分倒装
   - Only + 状语置于句首的倒装
   - 否定词置于句首的倒装
   - It is/was...that 强调句型

10. **主谓一致与比较结构**（Unit 10）
    - 语法一致原则、意义一致原则、就近原则
    - as...as, more...than, the most 结构
    - 比较级的修饰语

## 五、教学原则

1. **循序渐进**：新单词新语法按 单词 → 短句 → 完整句 递进出现
2. **高频复现**：已学词汇和语法在后续单元中反复出现并逐步加深
3. **分批添加**：每个数据文件按20条为一批次添加，防止大批量操作覆盖
4. **语境学习**：词汇和语法在真实语境中呈现，非孤立记忆
5. **语法融合**：每单元聚焦1-2个语法点，与主题词汇有机融合

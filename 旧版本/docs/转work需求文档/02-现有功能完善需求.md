# Earthworm v1.5「体验补全版」产品需求

## 1. 版本目标

让新用户能在 5 分钟内完成“注册 → 选课 → 完成一组练习 → 看懂结果”，让老用户能在 2 次点击内继续学习或开始复习，让内容创建者能安全地创建、校验、编辑和发布课程包。

### 1.1 成功指标

| 指标                           | 基线       | v1.5 目标 |
| ------------------------------ | ---------- | --------- |
| 注册后 24 小时内开始第一课比例 | 上线前采集 | 提升 20%  |
| 开始课程后的完成率             | 上线前采集 | ≥ 65%     |
| 上传解析成功率                 | 上线前采集 | ≥ 90%     |
| P0 前端可恢复错误占比          | 未系统覆盖 | 100%      |
| 核心页面键盘可操作率           | 未验收     | 100%      |

### 1.2 非目标

- 不在 v1.5 接入真实支付。
- 不上线 AI 内容生成。
- 不做好友、小组、评论。
- 不更换现有 Nuxt/NestJS 技术栈。

## 2. 全局交互规则

### 2.1 页面框架

- 桌面端顶部导航：Logo、首页、课程、学习记录、设置；右侧今日进度、主题、头像。
- 移动端底部导航：首页、课程、学习、复习、我的。
- 主内容最大宽度 1200px；表单最大宽度 720px；学习区最大宽度 960px。
- 页面标题下必须有一句说明；主要操作固定在标题区右侧。

### 2.2 按钮状态

每个按钮必须定义：

1. 默认：可点击，文案为动作。
2. Hover：仅增强颜色或阴影，不改变布局。
3. Focus：2px 品牌色焦点环。
4. Pressed：缩小不超过 2%。
5. Loading：保留原宽度，显示转圈和进行中文案。
6. Disabled：降低对比度并用 Tooltip 解释原因。
7. Success/Failed：通过 Toast 或就地反馈告知结果。

### 2.3 页面状态

| 状态          | 表现                       | 可执行动作     |
| ------------- | -------------------------- | -------------- |
| Loading       | 骨架屏，结构与真实内容一致 | 无             |
| Empty         | 插图/图标 + 原因 + 下一步  | 主 CTA         |
| Error         | 错误摘要 + 参考编号        | 重试、返回     |
| No permission | 解释访问规则               | 登录、返回课程 |
| Offline       | 顶部常驻提示，保留本地输入 | 重试同步       |

### 2.4 Toast

- 成功：3 秒自动消失，可手动关闭。
- 警告：5 秒。
- 错误：不自动消失，必须有“重试”或“查看详情”。
- 同类消息 2 秒内合并，不堆叠超过 3 条。

## 3.1 登录与注册 `/callback`

### 页面结构

- 左侧：产品价值、三条能力说明、返回首页。
- 右侧：登录/注册卡片。
- 移动端仅显示表单卡片，价值说明折叠到顶部。

### 登录按钮与控件

| 控件         | 条件/动作       | 结果                                       |
| ------------ | --------------- | ------------------------------------------ |
| 用户名输入框 | 必填，2–32 字符 | 失焦后显示字段错误                         |
| 密码输入框   | 必填，8–64 字符 | 支持回车提交                               |
| 显示密码按钮 | 点击            | 切换明文/密文，图标同步变化                |
| `登录`       | 字段有效        | Loading → 登录成功后返回 `redirect` 或首页 |
| `忘记密码`   | 点击            | v1.5 显示“联系管理员重置”说明弹窗          |
| `创建账号`   | 点击            | 切换注册表单，不刷新页面                   |
| `返回首页`   | 点击            | 返回 `/`                                   |

### 注册新增控件

| 控件               | 规则                                  |
| ------------------ | ------------------------------------- |
| 用户名             | 2–32 字符；实时检查重复时显示“检查中” |
| 密码               | 至少 8 位，包含字母和数字             |
| 确认密码           | 必须一致                              |
| 协议勾选           | 默认不选；未勾选不可注册              |
| `注册并开始学习`   | 成功后自动登录并返回来源页            |
| `已有账号，去登录` | 切换登录表单                          |

### 验收

- 登录失败区分账号不存在、密码错误、网络异常、服务异常。
- 连续失败 5 次触发 60 秒冷却并显示剩余时间。
- 登录后不丢失原访问目标。

## 3.5 上传课程包 `/course-pack/upload`

### 三步流程

#### 第一步：选择文件

| 按钮            | 动作                     |
| --------------- | ------------------------ |
| `查看格式要求`  | 打开格式、示例和限制抽屉 |
| `下载示例包`    | 下载仓库维护的有效示例   |
| `选择 ZIP 文件` | 打开系统文件选择         |
| 拖拽区          | 接收单个 `.zip`          |
| `取消`          | 返回课程中心             |

限制：ZIP ≤ 50MB、课程 ≤ 50、每课语句 ≤ 1000、解压后 ≤ 200MB、路径深度 ≤ 5。

#### 第二步：校验与编辑

- 顶部显示文件名、大小、课程数、语句数、错误数、警告数。
- 错误阻止下一步；警告允许继续。
- 每条错误包含路径，如 `data/02.json > 第 18 条 > english 不能为空`。

| 按钮               | 动作                      |
| ------------------ | ------------------------- |
| `重新选择`         | 确认后清空当前解析        |
| `只看错误`         | 筛选问题项                |
| `展开全部`         | 展开所有课程摘要          |
| `查看数据`         | 展开前 20 条并支持搜索    |
| `修正`             | 定位到可编辑字段          |
| `重新校验`         | 对当前数据再次执行 Schema |
| `下一步：发布设置` | 无错误时进入第三步        |

#### 第三步：发布设置

字段：封面、标题、描述、语言、难度、标签、可见性。

可见性默认 `私有`：

- 私有：仅创建者可见。
- 公开：所有人可搜索，勾选“我确认内容可公开”后才可发布。
- 会员：创始会员可访问。

| 按钮             | 动作                 |
| ---------------- | -------------------- |
| `上一步`         | 返回校验页并保留数据 |
| `保存为私有草稿` | 创建私有课程包       |
| `发布课程包`     | 按选择可见性创建     |
| `取消上传`       | 二次确认后离开       |

成功页提供：`查看课程包`、`继续编辑`、`再上传一个`、`返回课程中心`。

## 3.6 学习页 `/game/:coursePackId/:id`

### 布局

- PC 端学习会话使用独立全屏布局，不显示工作台侧栏、全局导航、用户菜单或页面 Footer。
- 顶栏：返回、课程标题/进度、计时、设置、暂停。
- 主区沿用现有游戏交互：中文题目、按英文单词长度拆分的下划线输入槽、隐藏键盘输入框和即时反馈；不得改成普通大文本框。
- 底栏：上一题、提示、发音、标记掌握、跳过、提交/下一题。
- 退出学习后才恢复工作台导航；暂停弹窗和学习设置不得使全局导航重新出现。

### 按钮明细

| 按钮       | 快捷键             | 动作                                             |
| ---------- | ------------------ | ------------------------------------------------ |
| `返回课程` | —                  | 有未同步数据时确认离开                           |
| `课程目录` | —                  | 打开可搜索目录                                   |
| `设置`     | —                  | 打开本次学习设置                                 |
| `暂停`     | 用户配置           | 停止计时并遮挡题目                               |
| `上一题`   | 用户配置           | 回到上一条，不覆盖历史结果                       |
| `提示`     | 用户配置           | 第一次显示词数，第二次显示首字母，第三次显示答案 |
| `播放发音` | 用户配置           | 播放当前英文，加载中禁用                         |
| `掌握`     | 用户配置           | 标记后从默认练习队列移除，可撤销 5 秒            |
| `跳过`     | 用户配置           | 记录跳过并进入下一题                             |
| `提交答案` | Enter/Space 按设置 | 校验答案                                         |
| `下一题`   | Enter              | 正确后进入下一题                                 |

### 答案反馈

- 正确：绿色图标、正确答案、用时；自动下一题按设置执行。
- 错误：只高亮差异片段；显示第几次错误。
- 第三次错误：按设置自动给答案，并加入待复习。
- 网络断开：继续本地答题，顶部显示“离线，数据待同步”。

### 暂停弹窗

显示已学习时长、当前进度。按钮：

- `继续学习`：关闭并恢复计时。
- `稍后继续`：保存进度并回首页。
- `结束本次`：进入中途结算，不标记课程完成。

## 3.9 设置 `/user/setting`

### 分组

1. 学习模式。
2. 答题行为。
3. 发音与声音。
4. 快捷键。
5. 外观。
6. 数据与隐私。

### 通用行为

- 每次更改自动保存，右上显示 `保存中…` → `已保存`。
- 网络失败显示 `未同步` 和 `重试`，本地值不回滚。
- 页面底部有 `恢复默认设置`，确认后恢复全部默认。

### 每个控件

| 设置             | 控件                | 默认     |
| ---------------- | ------------------- | -------- |
| 学习模式         | 中译英/听写分段选择 | 中译英   |
| 显示单词长度     | Switch              | 开       |
| 空格提交         | Switch              | 关       |
| 正确后自动下一题 | Switch              | 关       |
| 输错三次显示答案 | Switch              | 开       |
| 键盘音效         | Switch + 音量滑块   | 关，50%  |
| 答案页自动发音   | Switch              | 开       |
| 答题时自动发音   | Switch              | 关       |
| 口音             | 美音/英音           | 美音     |
| 主题             | 跟随系统/浅色/深色  | 跟随系统 |
| 减少动画         | Switch              | 跟随系统 |

快捷键每行按钮：`编辑`、`清除`。编辑弹窗按钮：`取消`、`保存`、`恢复该项默认`。发生冲突时禁止保存并指出冲突功能。

## 3.10 会员入口

v1.5 不接支付。所有“升级”入口统一进入权益说明页：

- 展示免费版和创始会员真实差异。
- 价格区改为“早期支持计划，暂未开放购买”。
- 主按钮 `加入开放通知`，提交邮箱或使用账号邮箱。
- 次按钮 `继续使用免费版`。
- 禁止调用 `membership/buy`。

后端 `membership/buy` 在生产环境关闭，直到订单、支付回调、签名、退款、幂等与财务对账全部具备。

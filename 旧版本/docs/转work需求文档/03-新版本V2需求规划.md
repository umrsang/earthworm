# Earthworm v2.0「学习工作台」产品需求

## 1. 产品定义

v2.0 从“完成一门课程的答题工具”升级为“每天告诉用户学什么、复习什么、为什么”的英语学习工作台。

核心闭环：

```text
设定目标 → 系统生成今日计划 → 学习新内容
      ↑                         ↓
看懂报告 ← 完成复习 ← 错题与掌握度进入调度
```

## 2. 用户与核心任务

### 2.1 学习者

- 每天打开后快速知道今天该做什么。
- 在碎片时间完成 5–20 分钟学习。
- 复习真正容易忘的内容，而不是重复全部内容。
- 能看到自己的正确率、连续性和薄弱点。

### 2.2 内容创建者

- 安全创建和维护课程。
- 知道课程是否被学习、完成和收藏。
- 根据错误率发现内容问题。

### 2.3 平台运营

- 组织官方课程和主题合集。
- 控制公开内容质量。
- 观察学习漏斗和内容表现。

## 3. v2.0 范围

### 必做

- 每日学习计划。
- 错题本与间隔重复队列。
- 学习报告与趋势。
- 课程发现、搜索、收藏。
- 完整课程创作工作台。
- 响应式移动端。

### 延后

- 实时语音评分。
- AI 自动生成课程。
- 好友、聊天、小组。
- 真正支付。
- 原生 App。

## 5. 页面与按钮级需求

## 5.1 今日工作台 `/today`

### 页面区块

1. 顶部问候、连续学习天数和日期。
2. 今日目标环。
3. 今日计划队列。
4. 继续学习。
5. 一周趋势。

### 今日目标卡

显示 `已完成 12/20 句 · 9/15 分钟`。

| 按钮           | 动作                             |
| -------------- | -------------------------------- |
| `开始今日计划` | 顺序打开第一条未完成任务         |
| `继续今日计划` | 从中断任务继续                   |
| `调整`         | 打开目标与计划弹窗               |
| `查看今日详情` | 展开任务、完成记录和预计剩余时间 |

### 计划任务

任务类型：新课、到期复习、错题巩固。

每条显示来源、题量、预计时间、优先级、完成状态。

| 按钮        | 动作                         |
| ----------- | ---------------------------- |
| 任务主体    | 打开任务                     |
| `开始/继续` | 进入对应模式                 |
| `稍后`      | 移到今日队列末尾，仅一次     |
| `移出今日`  | 确认后移出，但保留在复习中心 |
| `完成详情`  | 已完成任务查看报告           |

### 计划设置弹窗

- 每日分钟：5/10/15/20/30/45/60。
- 新内容占比：20%–80%。
- 每日上限：10–100 句。
- 学习日：周一至周日多选。
- `取消`、`保存并重新生成计划`。
- 重新生成前展示“已完成任务不会改变”。

- `为你推荐`
- `全部课程`

### 搜索和筛选

- 搜索标题、主题、创建者。

- 排序：推荐、热门、最新、评分。

### 推荐解释

卡片显示一条原因：`适合你的 A2 水平`、`补强过去 7 天高频错误`、`与你收藏的旅行英语相似`。

### 卡片按钮

| 按钮       | 动作                   |
| ---------- | ---------------------- |
| `查看课程` | 进入详情               |
| `开始学习` | 添加到学习并进入第一课 |
| `继续学习` | 打开上次进度           |
| `收藏`     | 状态即时切换           |
| `更多`     | 不感兴趣、分享、举报   |
| `不感兴趣` | 选择原因后从推荐移除   |
| `举报`     | 打开类型和说明表单     |

## 5.3 课程详情 `/courses/:id`

新增内容：

- 学习收益。
- 适合人群与前置能力。
- 课程大纲。
- 样例题。
- 创建者信息。
- 内容统计和更新日期。
- 学习者评分摘要（v2.0 只读，可延后开放写评论）。

| 按钮           | 动作                               |
| -------------- | ---------------------------------- |
| `开始学习`     | 加入“我的课程”并进入第一课         |
| `加入今日计划` | 选择每天题量后加入                 |
| `试学 5 题`    | 匿名也可打开固定样例               |
| `收藏`         | 收藏                               |
| `分享`         | 复制链接/二维码                    |
| `查看全部大纲` | 展开所有课                         |
| 课程行         | 已加入用户可进入；未加入先确认加入 |
| `查看创建者`   | 打开创建者公开页                   |

## 5.4 学习会话 `/learn/:sessionId`

会话可包含多个课程来源，但一次只显示一种题型。

PC 端为独立全屏专注模式：进入会话后隐藏工作台侧栏、全局导航、用户菜单与 Footer，只保留退出、课程进度、计时、暂停和本次设置。退出或完成会话后恢复工作台框架。

### 题面

- 任务来源和题号。
- 中文题目/音频。
- 可选语法提示。
- 输入区。
- 反馈区。

### 按钮

| 按钮       | 动作与记录                   |
| ---------- | ---------------------------- |
| `退出`     | 保存会话，弹出退出确认       |
| `目录`     | 查看本会话队列               |
| `暂停`     | 停计时                       |
| `提示`     | 分层提示，记录提示级别       |
| `发音`     | 播放，记录但不影响评分       |
| `不认识`   | 直接显示答案并进入高优先复习 |
| `标记问题` | 选择翻译错误/音频错误/其他   |
| `提交`     | 校验并记录 attempt           |
| `下一题`   | 正确或看答案后可用           |
| `撤销掌握` | 5 秒内撤销                   |

### 自适应规则 v2.0

- 首次正确且未用提示：熟练度 +2。
- 首次正确但用提示：+1。
- 第二次及以后正确：0。
- 看答案或不认识：-2。
- 同一句连续 3 次首次正确，可建议标记掌握。
- 算法只决定复习时间，不在 v2.0 动态修改课程难度。

## 5.5 复习中心 `/review`

### 顶部

显示：今日到期、错题、即将到期、已掌握。

### 标签

- `今日到期`
- `错题`

- `已掌握`

### 列表与批量操作

| 按钮        | 动作                       |
| ----------- | -------------------------- |
| `开始复习`  | 按优先级生成最多 20 题会话 |
| `快速 5 题` | 生成 5 题                  |
| `自选复习`  | 进入勾选模式               |

| `撤销`      | 对刚执行的批量操作恢复     |

### 复习项字段

英文、中文、来源、上次结果、错误次数、下次复习时间、熟练度 1–5。

## 5.6 学习数据 `/insights`

### 时间范围

`7 天`、`30 天`、`90 天`、`今年`、`自定义`。

### 指标

- 学习时长。
- 完成句数。
- 首次正确率。
- 连续学习天数。
- 复习按时完成率。
- 掌握数。

### 按钮

| 按钮                   | 动作                     |
| ---------------------- | ------------------------ |
| 时间范围               | 刷新全部图表，并写入 URL |
| `查看计算方式`         | 打开指标定义             |
| 图表点                 | 展示该日详情             |
| `查看全部历史`         | 打开按日列表             |
| 历史行                 | 展开课程、复习、错误明细 |
| `导出 CSV`             | 生成当前范围数据         |
| `薄弱点：开始专项复习` | 按标签生成复习会话       |

不使用饼图表达时间趋势；趋势使用折线，构成使用堆叠柱。

## 5.7 创作工作台 `/creator`

### 概览

我的公开课程、私有草稿、总学习人数、近 30 日完成次数。

### 按钮

| 按钮         | 动作                                 |
| ------------ | ------------------------------------ |
| `新建课程包` | 选择空白、模板、上传 ZIP             |
| `继续编辑`   | 打开草稿                             |
| `查看数据`   | 打开内容表现                         |
| `复制`       | 创建私有副本                         |
| `发布`       | 进入发布检查                         |
| `下架`       | 确认后从发现页移除，不删除学习者数据 |
| `删除草稿`   | 输入标题确认                         |

### 编辑器 `/creator/course-packs/:id`

左侧树：课程包 → 课程 → 语句。中间编辑区。右侧校验和预览。

| 按钮          | 动作                           |
| ------------- | ------------------------------ |
| `新增课程`    | 在当前课程后新增               |
| `新增语句`    | 在当前语句后新增               |
| `导入`        | JSON/CSV/ZIP                   |
| `预览学习`    | 以学习者视角打开               |
| `保存草稿`    | 手动保存；同时每 30 秒自动保存 |
| `发布检查`    | 执行完整校验                   |
| `撤销/重做`   | 最近 50 步                     |
| 树节点 `更多` | 重命名、复制、移动、删除       |
| `定位问题`    | 选择校验项并跳对应字段         |

### 发布检查

检查必填、重复句子、空课程、封面、权限、版权确认。全部通过才可 `发布`。

## 5.8 通知与提醒

v2.0 先支持站内与浏览器通知：

- 今日计划未开始。
- 到期复习。
- 连续学习即将中断。

按钮：

- `允许浏览器通知`：触发系统权限。
- `以后再说`：7 天后再提示。
- `通知设置`：进入设置。
- 系统拒绝后显示浏览器设置指引，不重复请求。

## 5.9 设置 `/settings`

在 v1.5 基础上新增：

- 每日计划。
- 复习强度。
- 通知时间。
- 数据导出。
- 删除账号。

危险区：

- `导出我的数据`：生成异步任务，完成后站内通知。
- `删除账号`：验证密码 → 说明 7 天冷静期 → 输入用户名 → 提交。
- 冷静期内提供 `撤销删除`。

## 9. 设计规范

### 9.1 视觉方向

- 保留深色紫色品牌基调，增加薄荷绿作为“正确/进度”强调。
- 大面积背景低饱和，装饰光晕只用于顶部或重要 CTA，不覆盖正文。
- 卡片分组依赖间距、边框和层级，不堆叠无意义玻璃效果。
- 一屏只允许一个最强主按钮。

### 9.2 响应式

| 宽度     | 行为                              |
| -------- | --------------------------------- |
| ≥ 1200   | 左侧导航 240px，主内容最大 1200px |
| 768–1199 | 左侧导航缩为 72px，只显示图标     |
| < 768    | 顶栏 + 底部五项导航，卡片单列     |

### 9.3 内容规范

- 按钮用动词：开始、继续、保存、发布。
- 不使用“确定”表达具体业务动作。
- 错误说明发生了什么、是否保存、下一步做什么。
- 不混用中英文按钮，产品名和技术格式除外。

## 10. 迭代计划

### Phase A：基础（2 个 Sprint）

- v1.5 前置条件完成。
- 新会话与 Attempt 模型。
- 今日工作台基础。
- 复习项生成。

### Phase B：学习闭环（2 个 Sprint）

- 复习中心。
- 新结算报告。
- 数据概览。
- 离线去重。

### Phase C：内容发现与创作（2 个 Sprint）

- 搜索推荐。
- 收藏。
- 创作工作台。
- 发布检查。

### Phase D：灰度与优化（1 个 Sprint）

- 10% 灰度。
- 对比旧首页的开始率、完成率、次日留存。
- 修复 P0/P1 后全量。

## 11. v2.0 验收场景

### 场景 A：新用户

1. 注册并回到课程详情。
2. 试学 5 题。
3. 加入课程并设置 15 分钟目标。
4. 完成第一课。
5. 结算页看到错题进入复习。

### 场景 B：老用户

1. 今日页显示 8 条到期复习。
2. 点击“快速 5 题”。
3. 离线完成 2 题，恢复网络后不重复计数。
4. 完成后今日目标更新。

### 场景 C：创建者

1. 上传 ZIP。
2. 定位并修复第 18 条空英文。
3. 保存私有草稿。
4. 预览学习。
5. 发布检查并公开。

以上场景需要桌面 1440px、平板 768px、手机 390px 三档 E2E 截图通过。

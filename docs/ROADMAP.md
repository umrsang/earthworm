# 产品功能规划路线图

## 项目概述

Earthworm 是一个基于游戏化拆句拼句的英语学习平台，支持中译英和听写两种学习模式。课程以三级结构组织：课程包（CoursePack）→ 课程（Course）→ 语句（Statement），用户可自建课程包并分享。

## v1.1 — 自建认证 + 课程包管理 ✅ 已完成

### 认证系统

- [x] 移除 Logto 和 Redis 依赖
- [x] 自建账号密码注册/登录
- [x] argon2 密码哈希 + JWT 令牌签发
- [x] 本地 AuthGuard 替代 Logto JWK 远程验证

### 课程包管理后台

- [x] 课程包上传（ZIP 解析 + 表单提交）
- [x] 课程包 CRUD（编辑标题/描述/免费/分享级别，删除含级联）
- [x] 课程 CRUD（编辑标题/描述，删除含级联）
- [x] 语句 CRUD（编辑中英文/音标/标注，删除）
- [x] CreatorGuard 三级权限检查（语句→课程→课程包）
- [x] 前端管理页面（hover 编辑/删除按钮，编辑弹窗，删除确认）

## v1.2 — 学习体验增强 ✅ 已完成（体验增强部分）

### 学习数据

- [ ] 学习天数连续记录与打卡日历
- [ ] 每日学习目标设定（句子数/时长）
- [ ] 学习统计数据仪表盘（总句子数、正确率、学习时长）

### 学习体验

- [x] 语音评测：浏览器端录音与发音对比（基于 Web Speech API，答案页一键评测，LCS 算法计算准确率）
- [x] 学习提醒：每日学习通知推送（浏览器 Notification API，可自定义提醒时间，每分钟检查当日是否已学习）
- [x] 夜间模式 / 主题切换（启用 CSS 变量全局应用，Navbar 快捷切换按钮，View Transitions 动画）
- [x] 键盘快捷键支持（支持 Alt/Shift/Ctrl/Command 四修饰键组合，可自定义快捷键配置）

## 长期愿景

- **自适应学习**：根据用户水平动态调整难度和内容
- **间隔重复**：基于遗忘曲线的智能复习计划
- **开放生态**：课程包格式标准化，跨平台互通
- **AI 个性化**：AI 学习助手，实时纠错和解释

## 原型页面入口

原型使用查询参数切换页面，直接双击 `prototype/index.html` 后也可通过页面按钮完整跳转。

| 页面        | 地址参数                   | 已覆盖交互                                                           |
| ----------- | -------------------------- | -------------------------------------------------------------------- |
| 登录页      | `?page=auth`               | 用户名/密码校验、密码显隐、保持登录、忘记密码说明、切换注册          |
| 注册页      | `?page=auth&mode=register` | 用户名、密码、确认密码、协议确认、字段级错误、切回登录               |
| 课程包上传  | `?page=upload`             | 选择文件、格式说明、解析校验、警告定位、信息编辑、发布设置、成功结果 |
| 上传校验态  | `?page=upload&step=2`      | 0 错误/2 警告示例、重新选择、重新校验、数据预览                      |
| 上传发布态  | `?page=upload&step=3`      | 私有/公开/会员专享、公开版权确认、保存草稿、创建课程包               |
| PC 全屏学习 | `?page=learn`              | 独立全屏、分词输入槽、提示、不会、提交、暂停和退出                   |

登录、注册和课程包上传均为交互原型，尚未接入真实接口，也不代表生产功能已经开发完成。

## 推荐阅读顺序

1. 产品、设计先评审现状审计，确认 P0/P1 范围。
2. 设计和研发按 v1.5 文档完成旧功能闭环。
3. v1.5 上线并观察两周数据后，再启动 v2.0。
4. 原型用于交互评审，不直接作为生产代码。

## 版本策略

```text
当前版本
  ↓ 先消除流程断点、错误承诺和状态缺失
v1.5「体验补全版」
  ↓ 验证学习闭环和留存指标
v2.0「学习工作台」
```

v1.5 不新增大而散的功能，重点是让登录、选课、学习、完成、复习、管理、会员入口都“能找到、能理解、能完成、能恢复”。v2.0 再围绕每日学习计划、错题与间隔复习、课程发现建设新能力。
